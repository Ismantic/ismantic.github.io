Unicode -> Regex -> Trie -> Tokenize -> CRF -> LDA -> W2V -> GPT，这条路线几乎可以当作一份压缩过的 NLP 技术编年史。它不只是若干模型的罗列，而是文本系统在工程上一步步被“驯化”的过程。

先有 Unicode，文本才真正成为可计算、可交换、可持久化的对象。没有统一编码，后面的分词、索引、训练和生成都不成立。很多人一上来就讨论模型，其实最底层的问题一直是“字符到底是什么”。编码一旦不稳，整个系统从输入开始就是脏的。

Regex 是第二层。它代表的是人类最早一批对文本结构进行显式描述的方式。邮箱、日期、标点、空白、模板化语句、日志切分，这些都不是“大模型问题”，而是模式匹配问题。Regex 的价值不在于它高级，而在于它把“文本里哪些东西可以被规则直接拿下”这个边界先划清了。

Trie 再往前走一步，把字符串处理推进到高效索引和词典组织。无论是词表匹配、前缀补全、敏感词检测，还是搜索建议，Trie 都是在用空间换时间。它提醒我们，NLP 从来不只是统计学习，也是一门数据结构的学问。很多系统效果差，不是模型不够强，而是底层组织文本的方法太粗糙。

Tokenize 则是 NLP 真正进入“语言单位”阶段的入口。字符不是词，词也不一定是最终 token，但任何上层算法都必须先回答一个问题：模型究竟在处理什么单位。中文分词、子词切分、BPE、SentencePiece，本质都在解决表示粒度问题。粒度不同，信息密度、歧义形式和训练成本都会变。

CRF 代表结构化预测时代的一整套思想。它不是只会做序列标注，而是在告诉我们：语言任务中，相邻标签之间存在依赖，局部最优不等于全局最优。命名实体识别、词性标注、分词边界判断，这些任务都曾经被 CRF 认真定义过。它把“上下文约束”从启发式规则提升成了可训练的概率图模型。

LDA 让问题从“句子里这个词是什么角色”转向“整篇文本在谈什么主题”。这是另一种抽象层次。它不关心逐 token 的边界决策，而关心语料级别的隐含结构。主题模型那一代方法很重要，因为它建立了语义分布的直觉：词不是孤立出现的，文本背后有潜在的生成机制。

W2V 再往后，把“词的意义”压进向量空间。它的革命性不只在于 embedding，而在于它把分布式假设变成了工业标准：一个词出现的上下文，决定了这个词的语义位置。自那以后，语义相似、类比推理、下游迁移都开始建立在连续表示上。NLP 开始从离散符号工程，转向连续空间学习。

GPT 则把前面这些脉络统一进一个更大的预测框架里。编码、切分、表示、上下文建模、知识压缩、生成能力，最后都汇总为“给定前文，预测下一个 token”。从这个角度看，GPT 不是凭空出现的奇迹，而是前面所有技术积累之后的自然收束。它吃掉了很多传统模块，但并没有抹去它们的意义；相反，越理解那些旧技术，就越能看清今天的大模型到底继承了什么、替代了什么、又忽略了什么。

所以这条路线的价值，不只是“从旧到新”的时间顺序，更是一种认知地图：从字符，到模式，到词典，到切分，到结构化建模，到主题抽象，到向量语义，再到生成式统一模型。沿着它往前看，几乎能把 NLP 的主要技术细节和思想转向都串起来。
